# PRD: 自己紹介AIチャット

最終更新: 2026-10-27 / 状態: 下書き

## 1. 問題文
サイトを訪れた人（採用担当・知人・初対面の人）が、僕のことを知りたいとき、プロフィールページを上から全部読まないと欲しい情報にたどり着けない。いまは静的な自己紹介文や口頭での説明でしのいでいるが、相手が知りたいことを知りたい順に聞けない。

## 2. ユーザーと利用場面
- 主な利用者: 不特定多数の訪問者（一般公開）。管理者は僕だけ。
- 使う場面・端末: SNSや名刺のリンクから開く。スマホが中心、PCも想定。
- 成功とは: 訪問者が知りたいこと（経歴・スキル・趣味・連絡先など）を、2〜3回の質問で知ることができた状態。

## 3. コアループ
ページを開く → 簡単な自己紹介を読む → 質問を入力する（または質問例を押す） → AIが profile.md に基づいて答える → 続けて質問する

## 4. ユーザーストーリー（Must のみ）
### US-1 質問して答えをもらう
訪問者として、僕について自由に質問したい。なぜなら知りたいことだけを早く知りたいから。
- 前提: ページを開いている
- 操作: 入力欄に「趣味は？」と入れて送信する
- 結果: profile.md の内容に沿った回答が表示される。回答は数秒以内に表示され始める

### US-2 書いていないことには答えない
訪問者として、正しい情報だけを受け取りたい。なぜなら作り話をされると誤解するから。
- 前提: profile.md に「好きな食べ物」が書かれていない
- 操作: 「好きな食べ物は？」と聞く
- 結果: 「その情報は書かれていないので分かりません」という趣旨の回答になり、内容を作り出さない

### US-3 会話を続ける
訪問者として、前の答えを受けて追加で質問したい。なぜなら深掘りしたいから。
- 前提: 1回質問して回答を受け取った
- 操作: 「それについてもっと詳しく」と聞く
- 結果: 直前の話題を踏まえた回答が返る

### US-4 質問例から始める
訪問者として、何を聞けばいいか迷わず始めたい。
- 前提: まだ何も質問していない
- 操作: 「どんな人？」などの質問例ボタンを押す
- 結果: その質問が送信され、回答が表示される

### US-5 使いすぎを防ぐ（管理者）
僕として、乱用で高額な請求が来ないようにしたい。
- 前提: 公開中
- 操作: 同じ人が短時間に大量に送信する／全体の利用が1日の上限に達する
- 結果: 「しばらくしてからお試しください」と表示され、APIは呼ばれない

## 5. スコープ
- Must（MVP）: 自己紹介の見出し部分、チャット（送信・回答表示・会話の継続）、質問例、回答を少しずつ表示（ストリーミング）、乱用対策（回数制限・1日の上限・文字数制限・回答の長さ上限）、スマホ対応
- Should（次の版）: 回答のMarkdown表示（箇条書き・リンク）、Cloudflare Turnstile（ロボット判定）、プロフィールの詳しいセクション表示、ダークモード
- Could: 英語対応、会話のリセットボタン、アクセス数の集計
- **やらないこと（Non-goals）**: ログイン、会話履歴のサーバー保存、管理画面、profile.md 以外の情報源（Web検索など）、profile.md をブラウザから編集すること

## 6. 制約
- 端末: スマホ中心、PCも
- データの置き場所: profile.md はリポジトリ内（Workerに同梱）。会話はブラウザのメモリ上だけ（リロードで消える）
- 利用者数: 不特定多数（ただし個人サイトなので1日数十〜数百回程度を想定）
- 公開範囲: 一般公開
- オフライン: 不要
- 外部連携: Anthropic Claude API
- データ量: profile.md は数千字程度
- 費用: GitHub Pages・Cloudflare Workers は無料枠。Claude API は従量課金（月の上限を設定）

## 7. リスクと検証
| リスク | 検証方法（スパイク） | 結果 |
|---|---|---|
| APIキーの漏洩 | キーはWorkerのSecretにだけ置き、ブラウザ側のコードに一切出てこないことを確認 | 未 |
| 乱用による高額請求 | Anthropic Consoleの月額上限＋Workerの回数制限で二重に止める | 未 |
| 書いていないことをAIが作り話する | 書いていない質問を10個ほど投げて確認し、指示文を調整 | 未 |
| 無関係な用途に使われる（タダのChatGPT代わり） | 指示文で「僕に関係ない話題は断る」＋回答長の上限 | 未 |

## 9. MVP 成功基準
- [ ] 公開URL（github.io）をスマホで開き、質問すると数秒以内に回答が出始める
- [ ] profile.md に書いていないことを聞くと「分からない」と答える
- [ ] 前の質問を踏まえた追加質問に答えられる
- [ ] 短時間に連続送信すると制限メッセージが出る
- [ ] ブラウザの開発者ツールでどこを見てもAPIキーが見つからない

## 10. 仮定（ユーザー未回答・お任せで採用したもの）
- AIは**本人として一人称**（「僕は〜」）で話す。後から指示文で変えられる
- profile.md の内容は**すべて公開情報**として扱う（チャットで聞けば出てくるので、隠しても意味がない）。公開したくないことは書かない
- 回答は日本語。英語で質問されたら英語で答える
